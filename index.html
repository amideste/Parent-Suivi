Appréciations

Aucun élève dans cette classe. Ajoutez un élève ou importez un fichier.
🔓 Carnet non protégé par code.
Plusieurs classes : utilisez le menu déroulant en haut pour changer de classe, « + Classe » pour en créer une nouvelle, « ≡ Plusieurs classes » pour en créer plusieurs d'un coup (ex. vos 8 classes), et « 🗑 Classe » pour supprimer la classe active. Chaque classe garde sa propre liste d'élèves, son coefficient et sa matière.
Matricule : colonne facultative, de 12 à 14 chiffres selon l'élève (aucune longueur fixe imposée) — le carnet fonctionne très bien sans, vous pouvez le renseigner plus tard.
Import CSV ou Excel (.xlsx) : une ligne d'en-tête suivie des colonnes nom,interro1,interro2,interro3,interro4,devoir1,devoir2 (ou matricule,nom,interro1,interro2,interro3,interro4,devoir1,devoir2 si vous incluez le matricule). En CSV, séparateur virgule ou point-virgule. En fichier Excel (.xlsx), les valeurs sont lues directement colonne par colonne dans le tableur — aucun séparateur n'est nécessaire, à condition de respecter cet en-tête.
Calcul : Moyenne interro = somme des interros saisies ÷ nombre d'interros saisies (2, 3 ou 4) — calculée dès qu'une seule note d'interrogation est renseignée. Moy. semestre = (Moy. interro + Devoir1 + Devoir2)/3 — sans coefficient. Moy. coefficiée = Moy. semestre × coefficient réglable en haut du tableau.
Rang : calculé automatiquement selon la moyenne coefficiée (1er = plus forte moyenne), quel que soit le tri affiché.
Tri : « A→Z Trier par nom » (alphabétique) ou « ↓ Trier par moyenne » (de la plus forte à la plus faible, sur la moyenne coefficiée).
Téléchargements : « Exporter résultats (CSV) » et « 📊 Télécharger (Excel) » produisent un fichier avec l'en-tête, les noms, les notes, les deux moyennes et le rang. « 🖨️ Imprimer / PDF » reste disponible séparément pour la version imprimée — choisissez « Enregistrer au format PDF » dans la fenêtre d'impression. Cela fonctionne dès qu'au moins un élève a une note.
Sauvegarde complète : « 💾 Sauvegarde complète » télécharge un fichier .json contenant TOUTES vos classes, tous les élèves, toutes les notes (les deux semestres) et vos réglages — à conserver précieusement (clé USB, email, cloud) car les données du navigateur peuvent être perdues en cas de vidage du cache ou de changement d'appareil. « 📂 Restaurer une sauvegarde » recharge ce fichier et remplace les données actuelles (une confirmation est demandée avant tout remplacement).
Capacité : le carnet accepte jusqu'à 80 élèves par classe (bouton « Ajouter … lignes vides » pour préparer la liste d'un coup).
Enregistrer les notes : les notes et moyennes sont déjà sauvegardées automatiquement à chaque saisie, mais le bouton « 💾 Enregistrer les notes » permet de forcer et confirmer l'enregistrement à tout moment.
Différence entre les deux boutons de sauvegarde : « 💾 Enregistrer les notes » confirme simplement l'enregistrement du travail en cours dans ce navigateur (déjà fait automatiquement à chaque saisie). « 💾 Sauvegarde complète », lui, crée une copie externe (fichier .json) de toutes vos données — c'est votre protection contre une perte totale (cache vidé, appareil changé, navigateur réinstallé). Pensez à faire cette sauvegarde complète régulièrement.
Verrouillage par code : dans la zone « Sécurité » (sous le tableau), le professeur peut définir un code d'accès au carnet, avec une question secrète pour le réinitialiser en cas d'oubli. Le bouton « 🔒 Verrouiller » (en haut) verrouille immédiatement le carnet ; l'icône 👁 permet d'afficher ou masquer le code saisi.
Les données sont sauvegardées automatiquement dans ce navigateur (aucune connexion internet requise).
